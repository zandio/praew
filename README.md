\# ✈️ เปรียบเทียบราคาตั๋วเครื่องบิน (Flight Price Comparator)



โปรแกรมค้นหาและเปรียบเทียบราคาตั๋วเครื่องบินจากหลายสายการบินแบบเรียลไทม์ ช่วยให้ผู้ใช้เจอตั๋วราคาดีที่สุดได้ง่ายและรวดเร็ว



\## ✨ ฟีเจอร์หลัก



\- 🔗 \*\*เชื่อมต่อข้อมูลราคาจริง\*\* — ดึงราคาตั๋วเครื่องบินสด ๆ จาก API ของสายการบิน/แพลตฟอร์มเปรียบเทียบราคา (เช่น Skyscanner API) ไม่ใช่ข้อมูลจำลอง

\- 🛫 \*\*เปรียบเทียบหลายสายการบินพร้อมกัน\*\* — แสดงผลราคาจากหลายสายการบินในหน้าเดียว เรียงลำดับตามราคา เวลาบิน หรือจำนวนจุดแวะพักได้

\- 🔔 \*\*แจ้งเตือนราคาตั๋ว\*\* — ผู้ใช้สามารถตั้งค่าเส้นทาง/วันเดินทางที่สนใจ แล้วรับการแจ้งเตือนทันทีเมื่อราคาตั๋วลดลงหรือปรับขึ้น

\- 🔍 \*\*ค้นหาแบบยืดหยุ่น\*\* — ค้นหาตามต้นทาง–ปลายทาง ช่วงวันเดินทาง และตัวกรองอื่น ๆ เช่น สายการบิน, ชั้นโดยสาร, จำนวนผู้โดยสาร



\## 🛠️ เทคโนโลยีที่ใช้



\- Frontend: \_ระบุสแต็กที่ใช้ (เช่น React, Vue)\_

\- Backend: \_ระบุสแต็กที่ใช้ (เช่น Node.js, Python)\_

\- External API: Skyscanner API (หรือ API สายการบิน/ตัวรวมราคาอื่น ๆ)

\- ระบบแจ้งเตือน: \_ระบุวิธีแจ้งเตือน เช่น Email, Push Notification, Line Notify\_

\## 🚀 การติดตั้งและใช้งาน (Installation)



1\. โคลนโปรเจกต์นี้ลงเครื่องของคุณ

&#x20;  ```bash

&#x20;  git clone https://github.com/your-username/flight-price-comparator.git

&#x20;  ```

2\. เข้าไปยังโฟลเดอร์โปรเจกต์และติดตั้ง dependencies

&#x20;  ```bash

&#x20;  cd flight-price-comparator

&#x20;  npm install

&#x20;  ```

3\. ตั้งค่า API Key ของสายการบิน/บริการที่ใช้ในไฟล์ `.env`

&#x20;  ```env

&#x20;  FLIGHT\_API\_KEY=your\_api\_key\_here

&#x20;  ```

4\. รันโปรแกรม

&#x20;  ```bash

&#x20;  npm start

&#x20;  ```



\## 🎯 วิธีใช้งาน



1\. กรอกต้นทาง ปลายทาง และวันเดินทางที่ต้องการ

2\. ระบบจะดึงและเปรียบเทียบราคาตั๋วจากหลายสายการบินให้อัตโนมัติ

3\. เลือกเที่ยวบินที่ต้องการ หรือกดตั้งค่าแจ้งเตือนเพื่อติดตามราคาต่อไปได้
