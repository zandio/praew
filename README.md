# 🎹 เปียโนแสนสนุก (Fun Piano for Kids)

โปรแกรมสอนเล่นเปียโนสำหรับเด็ก ที่ช่วยให้เด็ก ๆ ได้เรียนรู้โน้ตดนตรีผ่านหน้าจอที่มีสีสันสดใส สนุกสนาน และใช้งานง่าย ไม่ว่าจะเล่นบนคอมพิวเตอร์หรือมือถือก็ได้

🔗 [**ลองเล่น Live Demo ได้ที่นี่**](https://your-username.github.io/fun-piano-for-kids/)

## ✨ จุดเด่นของโปรแกรม

* 🎵 **บอกชื่อโน้ตแบบไทย** — แต่ละคีย์เปียโนจะแสดงชื่อโน้ต โด เร มี ฟา ซอล ลา ที ให้เด็กเห็นและเข้าใจได้ทันทีเวลากดเล่น
* 🔊 **เสียงเปียโนจริง** — กดคีย์แล้วได้ยินเสียงโน้ตดนตรีจริง ช่วยให้เด็กเชื่อมโยงชื่อโน้ตกับเสียงได้อย่างเป็นธรรมชาติ
* 🌈 **โทนสีสดใส** — ออกแบบ UI ด้วยสีสันสดใส น่าดึงดูด เหมาะกับเด็ก กระตุ้นความสนใจในการเรียนรู้
* 📱💻 **รองรับทุกอุปกรณ์** — ใช้งานได้ทั้งบน Desktop และ Mobile ปรับหน้าจอ (Responsive) ให้เหมาะกับทุกขนาดอุปกรณ์
* 🖱️ **ใช้งานง่าย** — อินเทอร์เฟซเรียบง่าย เหมาะสำหรับเด็กที่เพิ่งเริ่มหัดเล่นเปียโน

## 🛠️ เทคโนโลยีที่ใช้

* HTML5
* CSS3
* JavaScript

## 🚀 การติดตั้งและใช้งาน (Installation)

1. โคลนโปรเจกต์นี้ลงเครื่องของคุณ

```bash
   git clone https://github.com/your-username/fun-piano-for-kids.git
   ```

2. เข้าไปยังโฟลเดอร์โปรเจกต์

```bash
   cd fun-piano-for-kids
   ```

3. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ที่คุณต้องการ

```bash
   open index.html
   ```

หรือใช้ Live Server extension บน VS Code เพื่อรันแบบ local development

## 🎯 วิธีใช้งาน

1. เปิดโปรแกรมขึ้นมา จะเห็นคีย์เปียโนสีสันสดใสพร้อมชื่อโน้ตกำกับไว้บนแต่ละคีย์
2. คลิกหรือแตะที่คีย์เปียโนเพื่อฟังเสียงโน้ตนั้น ๆ
3. เหมาะสำหรับผู้ปกครองหรือครูใช้สอนเด็กให้รู้จักโน้ตดนตรีเบื้องต้น
